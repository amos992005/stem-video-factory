# Comic pilot illustrations

The eight PNG illustrations in this directory were generated for this pilot via Arena's built-in image generation tool. Dr. Volt's other poses used `dr_volt_pointing.png` as a visual identity reference. These are AI-generated images, not Twemoji, Iconify, or hand-drawn fallback assets. Flux/SDXL model provenance is not exposed by the tool and is therefore not asserted. The PNGs are kept in Git to make rerenders independent of image-provider availability.

Original generated files are preserved; rembg cutouts and die-cut effects are produced at render time. Image-content validation detects simple corruption and low entropy but cannot prove AI origin or guarantee semantic correctness.
